About

I'm a Computer Science student at the University of Utah, originally from Brazil. Outside of class I spend most of my time building mods and tools for games I play with friends, which has turned into hands-on experience with client/server architecture, network protocols, reverse engineering, data pipelines and UI design.

I care about software that is easy for other people to install, configure and debug: clear docs, sensible defaults, automated tests where they matter, and readable code. I'm looking for software engineering internship and entry-level opportunities.

Featured projects

LootunCoop

C# · .NET · Networking

A co-op multiplayer mod for the single-player game Lootun. One player hosts and up to two others join a mission that runs on the host and is mirrored live on their screens, with XP, loot and currency split between players.

  • Host-authoritative simulation over a custom TCP protocol
  • Interpolated state snapshots to smooth gameplay on laggy connections
  • Runtime patching with BepInEx + Harmony; networking layer kept engine-free so it's unit-testable
  • Test suite covering handshakes, version mismatch, 1 MB messages, timeouts and garbage input

Java · Fabric · UI

Java · Game design

A roguelike game mode for Cobblemon inspired by Pokémon Emerald Rogue: pick one partner and fight through procedurally chosen floors of routes, trainers, gyms, the Elite Four and the Champion.
